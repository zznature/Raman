# Raman Docs

This directory is currently only a local documentation index for the Raman package.

Current engineering notes live in the repository-level `docs/` directory:

- `../../docs/autofocus.md`: Z autofocus algorithm, parameters, failure modes, and implementation notes.
- `../../docs/calibration.md`: image-registration XY calibration algorithm, coordinate conventions, confidence checks, and implementation notes.

Do not list workflow, hardware setup, or calibration-record documents here until those files exist.
